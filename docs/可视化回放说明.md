# 可视化回放

在任务列表中选择任务，再在采集记录列表中选择一条记录，点击“可视化回放”。窗口会同时显示头部、左腕、右腕视频和 G2 模型。点击播放或暂停，拖动进度条可以同步查看画面与关节姿态；鼠标拖动模型可旋转视角，滚轮可缩放。

默认加载 `assets/genie_robot_description/urdf/G2_t2v2_crs_omnipicker.urdf` 和同目录资产中的视觉网格。这些模型资源从当前 G2 机器人本机 `/home/agi/app/share/genie_robot_description` 获取，URDF 与数据集提供的 G2 型号一致。缺少视觉网格时会在窗口提示。

回放使用 LeRobot 的 `observation.state`、`observation.gripper` 中左右夹爪实测位置以及对应帧的视频，并按 URDF 联动规则显示夹爪，不会发送机器人控制命令。旧记录如果没有夹爪数据，夹爪保持默认姿态；底盘位姿未采集。没有采集某个相机时，该画面会提示未采集。

为确保同步，当前版本只支持本界面每条记录包含一个 episode、每路视频一个 MP4 分块的数据集；视频帧数或 FPS 与关节数据不匹配时会报错。回放按数据时间轴播放，电脑处理不及时可能跳过显示帧，但相机和关节始终按同一个帧号更新。

依赖：现有 LeRobot 环境中的 OpenCV、PyArrow、NumPy；系统 Python 的 PyQt5 与 VTK 9。

## 真机回放的限位检查

真机回放前会检查整段动作目标与机器人报告的关节限位。单个目标超限不超过 0.002 rad 时，确认窗口会列出受影响的关节、帧数和最大偏差；确认后，回放进程将这些目标限制在机器人允许范围，原始数据集不会被修改。超过 0.002 rad 的目标会拒绝回放，并显示关节、帧号和具体数值。

轨迹速度超过 URDF 中的关节速度限值时，会按统一比例降低回放速度，并在确认窗口列出相关关节及实际比例；未超速的轨迹仍按录制速度回放。移动到起始位姿仍使用低速过渡。
