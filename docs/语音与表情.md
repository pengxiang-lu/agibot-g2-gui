# 语音与表情

位于“机器人操作”页。先连接顶部机器人 SSH，再使用本区域；不需要启用手动运动控制。在标题下方的“aispeech SSH”一行点击右侧“连接”，完成交互板密码验证。显示“已连接”后，音量、播报及表情按钮才可用；这些操作不再自动弹出密码窗口。会话失效或地址变化时提示重新连接，连接失败后可再次点击重试。连接空闲 10 分钟退出。密码通过 SSH 验证窗口输入，不保存到代码或配置。

- **音量**：滑条或数字框范围 0–100%，点击“设置音量”生效。“读取音量”查询当前实际值。初始 20% 是待设置值，不代表已经读取机器人。
- **播报**：输入 1–1000 字后点击“播报”，应用页面音量再请求朗读。
- **内置表情**：点击“刷新表情”读取交互板实际文件，选择后点击“切换表情”。当前固件有 21 个视频，包括默认待机、开心、眨眼、微笑、害羞、思考等。
- **上传表情**：选择 PNG/JPG/BMP/WebP 图片，或 MP4/MOV/MKV/AVI/WebM/GIF 视频。图片转成 8 秒静音 MP4；视频最多取前 120 秒，去除音轨。按脸屏原生尺寸输出 2670×1200、25 FPS、H.264。素材等比放大并居中裁剪铺满脸屏，不拉伸；比例不一致时会裁掉上下或左右部分。透明区域合成为黑色。旧文件需要重新上传才能应用此处理。单个输入文件最大 512 MB，电脑需要 FFmpeg。
- **循环显示**：勾选持续循环，取消后播放一次。“关闭脸屏”关闭显示，下次播放会重新开启。恢复待机时选择“默认待机 · idle”并切换。

开始媒体操作会停止本页手动运动；媒体控件有焦点时，方向键不会驱动底盘。上传及转码在后台执行，处理期间避免重复提交；退出程序时会等待正在进行的媒体操作。

文件经主机 SSH 转发到头部交互板 `agi@10.42.0.111`。它与主机是独立账号系统，使用各自的凭据。上传到 `/home/agi/gdk_resources/collection_faces/face_<随机编号>.mp4`，不会覆盖内置文件；先传 `.partial`，完成后重命名。断线可能留下未完成文件，已上传文件保留在专用目录。

当前头部固件使用 `/agibot/software/agent` 服务，旧主机 GDK 交互状态接口未能读取它。因此此功能通过 SSH 调用头部原生 ROS 服务：`GetVolume`、`SetVolume`、`PlayTts`、`VideoDisplayReq`、`SwitchDisplay`，沿用固件 ROS_DOMAIN_ID=4 及 DDS 配置。使用现有 `sudo -n` 权限运行短时调用，不修改服务配置、不重启服务。

视频请求后查询现有播放器 `/tmp/mpv-socket` 的路径，界面区分“请求已接受”和“已确认播放器切换”；没有确认时会明确提示查看脸屏。播报成功表示服务接受请求。

2026-11-24 验证：实际读取音量 27%；20% 音量播报“你好”，上传并播放黄色小脸，用户确认声音和表情均正常；随后恢复音量 27% 和默认待机表情。另通过界面状态、请求校验、SSH 跳板参数、图片转码测试。

## 导入音频

连接 aispeech SSH 后，点击文字播报右侧的“导入音频并播放…”，选择本地 MP3、WAV、FLAC、M4A、AAC、OGG、Opus、WMA 或 AIFF 文件。程序在后台转换为 16 kHz、单声道、16 位 PCM WAV，上传后按页面当前音量播放一次。音频不截断，不使用表情的循环设置；输入文件最大 512 MB。

文件保存到交互板 `/home/agi/gdk_resources/collection_audio/`，使用随机文件名并在完整上传后重命名。播放使用原生 `SetVolume` 和 `PlayAudioFile` 服务，优先级为 6。界面显示请求接受状态，不将其作为播放已结束的标志。该目录中的上传文件会保留。转码失败或上传失败时不会发送播放请求。

新增音频功能已通过本地格式转换、路径和音量校验、原生服务请求字段及未连接状态按钮测试；本次未进行真机音频试听。
