# 验证记录

日期：2026-11-23。电脑 LeRobot 版本：0.6.2，Python 3.12；机器人：G2A，机器人本机 GDK，SSH 地址 `192.168.31.11`。

## 实机验证

- SSH 只读运行 GDK，未安装软件、未发布控制 topic、未切换模式、未发送运动指令。
- 单相机 `--probe` 通过，收到并解码同步的状态、action 和图像。
- 默认配置（3 相机、30 FPS、最大宽度 640、JPEG 95 传输、电脑 CPU H.264 编码）真实采集 8 秒，保存 1 个 episode、240 帧。
- 状态和 action 均覆盖 22 个关节，无缺失关节。实测 HAL 消息的 DDS `source_ts_ns` 为 0，采用有效的 `protobuf.header.stamp`，保留整数纳秒精度。
- 三个输出 MP4 **逐帧解码**，每个均为 240 帧，无视频数量差异。
- 官方 `LeRobotDataset` 加载成功，首尾图像解码正常，数据帧数、episode 数和时间间隔检查通过。
- 状态与采样时刻最大偏差：3.742836 ms。
- 真实 action 与采样时刻的最大年龄：8.208167 ms，全部不晚于采样时刻。
- 三路相机与采样时刻的最大偏差均为 0.159815 ms。
- 关节状态最大变化约 0.000069 rad，符合本次基本静止的调试采集；不应将这条数据当作任务演示。
- 不使用 GPU。

实机数据位于 `datasets/debug_capture_20261123/`。

## 本地验证

- 完整的人工测试采集：2 个 episode，每段 10 帧，3 路视频；官方读回通过。
- 6 项自动化测试通过：零 DDS 时间戳回退到 Header、乱序消息中的因果 action 选择、关节名称顺序映射、部分二进制写入、拒绝未来 action、网络中断时保存有效前缀并返回错误。
- 中断测试保留 3 帧并标记 `interrupted_by_error`，官方读回通过。
