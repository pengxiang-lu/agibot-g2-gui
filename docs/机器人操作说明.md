# 机器人操作

程序包含“数据采集”和“机器人操作”两个分页，顶部共用 SSH 连接。

1. 连接机器人 SSH，进入“机器人操作”。该页面仅预览头部彩色相机，自动读取头部、躯干和双臂共 22 个关节的实测角度。
2. 停止 Genie Link 遥操作、导航及其他运动控制程序后，点击“启用手动控制”。连接本身不会发送运动命令。
3. 按住并拖动圆形摇杆：阿克曼模式用前后速度和转向角速度，左右横向拖动为原地转向；蟹行模式用前后与横向速度，支持斜移。中心 18% 为死区，松开鼠标回中停止。
4. 默认速度为 20%。100% 对应底盘线速度上限 0.25 m/s、角速度上限 0.40 rad/s。此处“阿克曼”按 GDK 文档指令语义实现，不单独设置底盘硬件转向几何。
5. 上身页面可选择头部、躯干、左臂、右臂，点击 ± 按实测当前位置移动 1°、2°、5° 或 10°。默认步长 1°，点动速度上限 0.15 rad/s，实际再乘速度比例。每次只控制一个关节；目标超过机器人提供的关节限位会被拒绝。
6. “停止操作”、切换分页、窗口失焦、反馈过期会停止手动操作。真机回放和原生复位期间不会同时使用本页面的控制通道。停止后需重新启用。

机器人端按约 100 Hz 运行检查与关节发送，底盘发送最高 20 Hz；电脑每 50 ms 更新操作请求。超过 300 ms 未收到电脑消息时，停止关节发送并尝试发送底盘零速度，随后退出。此机制依赖机器人端进程及 GDK 仍可运行；不能替代物理急停，也未验证底盘控制器在进程崩溃或电源异常情况下的独立超时停止行为。

已完成离线方向、死区、点动、失联处理和 Qt 鼠标/切页测试，以及真机只读关节查询。未进行真机运动测试；首次使用应从默认低速、小步长开始并验证方向与停止效果。

## 方向键控制

启用手动控制后，焦点自动进入摇杆。也可以点击摇杆再使用键盘。

| 模式 | ↑ / ↓ | ← / → |
| --- | --- | --- |
| 阿克曼 | 前进 / 后退 | 原地左转 / 原地右转 |
| 蟹行 | 前进 / 后退 | 向左平移 / 向右平移 |

按住移动，松开停止；组合方向键可以边行进边转向或斜移，组合输入归一化以限制速度。相反方向同时按下互相抵消。沿用页面速度比例，默认 20%。切换模式或速度会清除按键，需松开后重新按下。输入框、下拉框、弹窗有焦点时不会触发键盘移动；重新点击摇杆即可。鼠标操作、焦点变化会清除键盘移动，窗口失焦或切页停止并解除手动控制。
