# G2 LeRobot Qt 图形化采集

在终端启动：

```bash
bash /home/lpx/桌面/lerobot_dataset_collection/start_gui.sh
```

界面使用 Qt 5 / PyQt5。本机直接使用系统已安装的 PyQt5，无需额外安装。也可双击文件夹里的 `G2图形采集.desktop`；如桌面提示，先右键选择“允许启动”。

1. 点击“创建任务”，输入任务名称并选择该任务。
2. 检查机器人 SSH 地址，点击旁边的“连接”，按弹窗输入密码，等待显示“已连接”。再设置帧率、图像最大宽度和采集时长。时长为 `0` 时手动结束；也可填写秒数自动结束。
3. 勾选需要采集的相机，至少选择一个。关节状态、关节目标 action、左右夹爪实测位置及时间戳为必选项；底盘、深度、IMU 尚未接入。夹爪目标命令未采集。
4. 点击“开始采集”，等待数据源初始化和 3、2、1 秒倒计时；界面提示“已开始采集”后，在 Genie Link 上正常遥操作。同一界面会话会复用 SSH 连接；网络断开、机器人重启或连接失效后，请重新点击“连接”。关闭界面后连接会关闭，密码不写入文件。模拟测试不需要连接。
5. 点击“结束采集”，界面先提示正在保存，完成后提示“采集已停止，数据已保存”；数据会出现在任务数据列表。倒计时期间停止不会保存数据。选择一条记录可查看首帧状态和 action、打开数据目录或通过“可视化回放”同时查看视频和 G2 关节轨迹。

采集记录按 Episode 0、Episode 1……依次显示；删除记录后，界面按剩余记录的顺序重新编号。界面 Episode 是任务下的记录编号；每条记录本身仍是独立 LeRobot 数据集，其内部 episode 编号从 0 开始。每次开始都会创建一条单独的数据集，保存在 `gui_tasks/<任务ID>/recordings/<采集时间_ID>/`。同一任务下多条采集是多个独立数据集；不跨次追加到一个数据集。任务名称修改只影响界面和此后采集的描述，已保存数据中的任务描述不变。

“模拟测试”使用合成数据，不连接机器人，数据列表会明确标记。数据预览中的状态和 action 以弧度为单位。所有记录均写入 `capture_manifest.json`；如果数据流中断，会标记保存的有效前缀及原因。

相机默认头部、左右手，视频在电脑上用 CPU 编码。未启用或不存在的相机会导致初始化失败，减少勾选后重试。点击结束后，界面会等待数据完成保存；强制关闭会影响当前记录。

图形界面的开始和结束按钮独立于 Genie Link 的数据采集按钮。采集和 VR 按键监听只读取数据；真机回放功能会在用户确认后发送机器人运动指令。默认通过 SSH 连接机器人，密码通过系统弹窗输入，不写入文件。首次连接时请核对弹窗中显示的主机指纹。

详细的数据字段与同步方式见 [README.md](README.md)。

## PICO 按键控制采集

先在电脑界面选择任务并连接机器人 SSH，在 PICO 中打开 Genie Link 并连接机器人。SSH 下方的 VR 状态会显示 PICO USB、Genie Link 连接和按键流状态；使用无线连接时 USB 未检测到并不代表 Genie Link 未连接。

当状态显示“X 开始 / 停止采集”时，按一次左手柄 **X** 开始当前任务的采集，准备完成后沿用三秒倒计时；松开后再次按 X 会停止采集并等待保存。倒计时期间再次按 X 可取消采集，保存期间的 X 输入会被忽略。开始前需选择任务和至少一个相机。VR 按键监听中断时，采集不会自动结束，可使用界面的“结束采集”按钮。

X 的 Genie Link 原有按键绑定不会被修改；如有功能冲突，应在头显的按键重绑定中检查。此功能不启动或修改 Genie Link 遥操作模式，也不会发送遥操作运动命令。

## 工程目录

- `src/`：Qt 界面、采集器、SSH 弹窗和数据验证程序。
- `docs/`：使用说明和验证记录。
- `datasets/`：原有示例数据，保持原路径。
- `gui_tasks/`：图形界面创建的任务与采集数据，保持原路径。
- 根目录的 `start_gui.sh` 和 `run.sh` 分别启动图形界面与命令行采集。

本机启动器优先使用 LeRobot 环境中的 PyQt5；未安装时会使用 Ubuntu 系统的 PyQt5。其他设备需安装兼容 Python 版本的 PyQt5 和 LeRobot 依赖。

## 删除

选中采集记录后点击“删除记录”，可删除该条记录；选中任务后点击“删除任务”，可删除任务及其所有记录。两种操作都需要二次确认，删除后无法恢复。采集期间无法删除。


三相机及 URDF 轨迹回放的操作和限制见 [可视化回放说明](可视化回放说明.md)。
